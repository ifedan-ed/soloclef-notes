# FAQ

## Why won't the chat answer from the web?

A notebook's chat answers from the notebook's ticked sources, so you always
know where an answer came from. To bring in new material, search for it in
the Sources panel and add it. For a one-off web search, pick Exa or Tavily
from Tools: the results are cited but not added to the notebook.

## The chat can't find something that is in my file.

Check that the source is ticked and finished indexing. For scans, complex
tables or figures, use Re-index… in the source's menu with a hosted parser,
if the server offers one, or upload it again with Vision on.

## Local or a hosted parser: which should I use?

Start with Local: it is free and the file stays on the server. Use a hosted
parser, if the server offers one, for scanned documents and files where
tables and figures matter.

## How long does a Studio output take?

Usually a few minutes; long videos take longer. You can keep working
meanwhile. The bell shows when it is ready or has failed, and the phone app
gets a push.

## A Studio output failed.

Choose Try again on it in the Studio list. If it keeps failing, try fewer
sources or a narrower focus. If it says the output isn't available, the
server doesn't offer that kind.

## I changed a file in Nextcloud. Does the notebook update?

No. Nextcloud files are copied once. Use Refresh from Nextcloud in the
source's menu to fetch the new version. Google Drive files are checked for
changes by themselves.

## How do I get an account?

Choose Sign up on the sign-in page when the server offers it; otherwise
choose Request access, or ask through the server's contact page.

## How do I change my password?

On the website, use Settings, Security, Change password. In the phone app,
use More, Profile, Change password. If you have forgotten it, use Forgot
Password? on the sign-in page.

## Can it read or send my email?

It can read it, and it never sends on its own. Add a mailbox under Settings,
Connectors. From a Stalwart mailbox it can also write a draft, which is sent
only when you press Send. IMAP and Microsoft mailboxes are read-only. See
[Email](email.md).

## Why didn't my phone get a push?

Check Settings, Notifications, or More, Notifications in the app: each kind
has its own switch, and quiet hours hold pushes back. Nothing is pushed while
Soloclef is open in front of you. The inbox always keeps everything.

## I didn't get the email.

Check your spam folder first. A password-reset link works once, for an hour.
Automation results are emailed only to the person who made the automation,
and only with Email me each result on. If the server doesn't send email at
all, ask its administrator.
