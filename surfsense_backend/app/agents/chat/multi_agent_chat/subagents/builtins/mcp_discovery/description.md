MCP specialist: acts on the MCP servers the user has added (for example search, browsing, or file-storage servers). Searches, reads, creates, and updates records through those servers' tools, asking for confirmation before write actions.
Use whenever the task is to look something up in, or take an action through, one of the user's MCP servers. Call `get_connected_accounts` first when it's unclear which servers are connected. Not for reading the user's own uploaded files or notes (use the knowledge base specialist), general web pages (web crawler), or platform scrapers like Reddit/YouTube.
