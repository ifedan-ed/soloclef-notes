Notes are your own writing: answers you kept from a chat, things you typed
yourself, and results saved by automations. A note can belong to one
notebook, or to none.

## Writing notes

- In a notebook, open the Notes tab beside Studio and choose New note in
  this notebook.
- On the Notes page, in the left rail, choose New note. If the list is
  filtered to a notebook, the note goes there; otherwise it is in no
  notebook.
- Under a chat answer, Save to note keeps the answer as a note in that
  notebook. Its icon then changes to Saved to notes, which opens the note.

Notes save as you type. The status beside the title says Saving…, then
Saved. A new note is named after its first line with words in it, or
"Untitled note" if there is none.

Notes take Markdown: headings, lists, tables, code, links and maths.

## Letting a chat read a note

A note is not one of a notebook's sources until you say so.

- In the notebook's Notes tab, switch a note's Source switch on.
- In an open note, choose Use as a source and switch on each notebook whose
  chat should read it. The button then says how many notebooks use it.

Nothing is copied. The chat reads the note as it is now, including later
edits.

## The Notes page

Notes, in the left rail, lists all your notes. Pinned notes come first, then
the rest by Last edited, Newest first or Title. You can narrow the list to
All, Pinned, From chats, Not in a notebook, or one notebook. Search your notes
finds notes by title or text and shows the passage that matched.

Each row shows the note's notebook, whether it came From a chat or From an
automation, whether it is a source, and when it was last edited.

## A note's menu

Open a note and use its More actions menu:

- Pin to the top, or Unpin.
- Move to another notebook, or File in a notebook for a note in none.
- Take out of the notebook.
- Delete.

A note kept from a chat links back to it with From a chat: open the
conversation.

## Notes from automations

An automation set to save its result in a notebook adds a note after each
run, named after the automation and the date, such as "Weekly digest, 5
October 2026". See [Automations](/docs/automations).

When a notebook is deleted, its notes stay, as notes in no notebook.
