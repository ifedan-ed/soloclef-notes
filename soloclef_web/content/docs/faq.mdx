<Accordion type="single" collapsible>
  <AccordionItem value="web">
    <AccordionTrigger>Why won't the chat answer from the web?</AccordionTrigger>
    <AccordionContent>
      A notebook chat answers only from the notebook's ticked sources, so you
      always know where an answer came from. To bring in new material, search
      for it in the Sources panel and add it. For a one-off web search, pick a
      tool from **Tools**; its results are cited as Web and not added to the
      notebook.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="missing">
    <AccordionTrigger>The chat says it can't find something that is in my file.</AccordionTrigger>
    <AccordionContent>
      Check that the source is ticked and has finished indexing. For scans,
      complex tables or figures, try uploading it again with the **Cloud**
      parser, or with **Vision** on.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="parser">
    <AccordionTrigger>Local or Cloud parser: which should I use?</AccordionTrigger>
    <AccordionContent>
      Start with **Local**: it is free and the file stays on the server. Use
      **Cloud** for scanned documents and files where tables and figures
      matter.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="studio-time">
    <AccordionTrigger>How long does a Studio output take?</AccordionTrigger>
    <AccordionContent>
      Usually a few minutes; long videos take longer. You can keep working
      while it is made, and turn on browser notifications to hear when it is
      ready.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="failed">
    <AccordionTrigger>A Studio output failed.</AccordionTrigger>
    <AccordionContent>
      Choose **Try again** on it in the Studio list. If it keeps failing, try
      fewer sources or a narrower focus.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="nextcloud">
    <AccordionTrigger>I changed a file in Nextcloud. Does the notebook update?</AccordionTrigger>
    <AccordionContent>
      No. Nextcloud files are copied once. Use **Refresh from Nextcloud** in the
      document's menu to fetch the new version.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="cost">
    <AccordionTrigger>Does it cost anything?</AccordionTrigger>
    <AccordionContent>
      Not yet: payments are not open, so nothing can be charged. Credits are
      counted, though, and each plan has a monthly allowance. When it runs
      out, work that costs credits stops until the next allowance. See
      [Plans and credits](/docs/plans-and-credits).
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="email-read">
    <AccordionTrigger>Can it read or send my email?</AccordionTrigger>
    <AccordionContent>
      It can read it, never send it. Add a mailbox under **Workspace settings →
      Connectors → Email (IMAP)**, with an app password if you use two-factor
      sign-in. The assistant can then search and read it, read-only: it never
      sends, deletes, moves or flags mail, and mail is never imported as a
      source. Mail is read in chats, notebook chats included, and in
      automations whose tasks can use the web.
      In a shared workspace, the other members' chats and automations can
      search it too. See [Email](/docs/email).
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="email-missing">
    <AccordionTrigger>I didn't get the email.</AccordionTrigger>
    <AccordionContent>
      Check your spam folder first. A password-reset link works once and
      expires after 30 minutes, and one address is sent at most 3 an hour:
      further requests send nothing. If an invitation email couldn't be sent,
      the person who invited you sees "Invitation created, email not sent" and
      can copy the link to you. Automation results are emailed only to the
      person who created the automation, and only when **Email me the result**
      is on. See [Email](/docs/email#emails-the-app-sends-you).
    </AccordionContent>
  </AccordionItem>
</Accordion>
